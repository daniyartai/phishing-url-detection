# PhishScan KZ

**Распознавание фишинговых ссылок с помощью машинного обучения**

## О проекте

PhishScan KZ — сервис, который по тексту ссылки за доли секунды определяет, является ли она фишинговой, и объясняет вердикт. Страница по ссылке не открывается, поэтому проверка безопасна. Сервис предоставляется через API, который банк встраивает в собственные каналы: мобильное приложение, чат поддержки, контакт-центр.

| Аспект | Описание |
|---|---|
| **Проблема** | Ущерб от интернет-мошенничества в Казахстане за 2025 год — 12,2 млрд ₸, на фишинг приходится 18,5% случаев. Чёрные списки обнаруживают новые сайты с запаздыванием |
| **ML-задача** | Бинарная классификация ссылки — фишинговая или легитимная — с объяснением вердикта |
| **Данные** | Набор PhiUSIIL (UCI, 2024; 235 795 ссылок), ежедневно обновляемые фишинговые фиды OpenPhish и Phishing.Database, рейтинг легитимных доменов Tranco |
| **Метрики** | Recall при FPR ≤ 1% на свежих данных, PR-AUC, ROC-AUC, калибровка, время ответа |
| **Бизнес-эффект** | Предупреждение до перехода по ссылке, в том числе для сайтов «нулевого часа»: снижение потерь клиентов и нагрузки на контакт-центр |
